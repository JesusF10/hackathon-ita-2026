# Automatización

Desde la raíz: `uv run --locked python scripts/check_docs.py` valida documentación; `uv run --locked python scripts/build_docs.py` compila el manual con Typst 0.15.1 instalado. Lee `docs/DEVELOPMENT.md` y `docs/typst/README.md`. Los scripts no descargan paquetes Typst; la primera sincronización de uv sí requiere red.

Estado: espacio reservado; no implica implementación ni un servicio independiente. Las rutas entre backticks son relativas a la raíz del repositorio.
