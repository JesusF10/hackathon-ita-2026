# Demo y pitch

Duración exigida en el material: tres minutos. Confirmar canal, horario y formato con la organización. Este guion es propuesta del equipo.

| Tiempo propuesto | Contenido |
| --- | --- |
| 0:00–0:15 | Nombre del proyecto y equipo; necesidad ciudadana |
| 0:15–0:40 | Problema concreto y relación con reto 3 |
| 0:40–1:00 | Solución y diferencia práctica |
| 1:00–2:05 | Buscar trámite, revisar evidencia, orientar y marcar progreso personal |
| 2:05–2:40 | Validación real disponible, impacto esperado, viabilidad y sostenibilidad |
| 2:40–3:00 | Equipo, siguiente paso y llamado a la acción |

Preparar antes: nombre, roles, jurisdicción piloto, fuente/fecha por dato, versión del prototipo, resultados de pruebas y estado de verificaciones legales. Las referencias legales del ejemplo requieren revisión oficial antes de afirmarse vigentes.

La demo debe mostrar un caso con evidencia y uno sin respuesta suficiente. Rotular datos sintéticos y avances personales. No simular conexión gubernamental ni presentar un video como servicio en vivo. Tener capturas o grabación de respaldo claramente identificadas, sin secretos ni personas identificables. Ensayar sin red y cronometrar.

Relacionar evidencias con los criterios de `EVENT.md`. No inventar cifras de usuarios, ahorro, precisión o corrupción evitada. Separar lo implementado, lo validado y lo proyectado.
